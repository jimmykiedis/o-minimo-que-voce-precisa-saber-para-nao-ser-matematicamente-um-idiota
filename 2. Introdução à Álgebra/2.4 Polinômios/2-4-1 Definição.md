# 2.4.1 Definição


## 📚**Definição de polinômio**
	Um polinômio é uma expressão algébrica formada por uma soma de monômios, onde cada monômio é composto por um coeficiente numérico multiplicado por uma variável elevada a um expoente natura (numero inteiro ≥ 0)

## ⚠️ **O que NÃO é um polinômio**
	* 1 /  <span style="font-family: STIXTwoMath-Regular;">
     𝑥
 </span> → Não é polinômio (expoente negativo)
	* √  <span style="font-family: STIXTwoMath-Regular;">
     𝑥
 </span> → Não é polinômio (expoente fracionário)
 <span style="font-family: STIXTwoMath-Regular;">
     	* 𝑥
 </span> <span style="font-size: 13.0;">
     <sup>-2 </sup>
 </span>+ 3 → Não é polinômio (expoente negativo)

## 🧠 **Resumo rápido**
	✅ Polinômio → Expoentes naturais (0, 1, 2, 3...)
	✅ Coeficientes → Números reais
	❌ Não pode expoentes negativos, fracionários ou variáveis no denominador.

# 1.3.3. Propriedades das operações


```
	⚙️“Não é bruxaria, é matemática bem comportada.”

```


## 🏠Introdução
	As operações fundamentais segue algumas leis que mantêm a ordem no caos. Elas dizem o que você pode trocar, agrupar, distrubuir e ignorar sem medo de dar uim. Tipo leis da física, só que nos números.

## 1️⃣Propriedade Comutativa
	"Pode trocar que dá na mesma."
		Adição:
			a + b = b + a
		Multiplicação:
			a * b = b * a
	📌Não vale pra subtração e divisão!

## 2️⃣Propriedade Associativa
	"Agrupa como quiser."
		Adição:
			(a + b) + c = a + (b + c)
		Multiplicação:
			(a * b) * c = a * (b * c)
	📌 Subtração e divisão? Também não entram nessa brincadeira!
	🧠 Veja que usamos um padrão reverso do “faturamento”, como se colocássemos o a em evidência.

## 3️⃣Propriedade Distributiva
	"Espalha o número para quem tá dentro do parênteses."
		Multiplicação sobre adição:
			a * (b + c)  = a * b + a * c

## 4️⃣Elemento Neutro
	"É o número que não muda nada."
| Operação        | Elemento Neutro | Exemplo         |
|-----------------|-----------------|-----------------|
| Adição          | 0               | a + 0 = a       |
| Multiplicação   | 1               | a * 1 = a       |


## 🧠 Resumo
| Propriedade                             | Rola com...                             | Moral da história                       |
|-----------------------------------------|-----------------------------------------|-----------------------------------------|
| Comutativa                              | + e ×                                   | Trocar ordem? Tá suave.                 |
| Associativa                             | + e ×                                   | Agrupa como quiser.                     |
| Distributiva                            | × sobre +                               | Espalha a multiplicação nos parênteses. |
| Elemento Neutro                         | 0 (soma) e 1 (produto                   | Adiciona sem alterar.                   |

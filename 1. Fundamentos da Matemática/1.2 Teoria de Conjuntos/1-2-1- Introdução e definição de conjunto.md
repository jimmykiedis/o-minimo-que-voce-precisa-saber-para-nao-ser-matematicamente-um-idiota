# 1.2.1. Introdução e definição de conjunto

# 
## 🎯 **Objetivo**
	Compreender o que é um conjunto, como ele é representado e por que é considerado a base da matemática moderna.

## 📚 **Definição**
	Um conjunto é uma coleção bem definida de elementos. Chamamos de **elemento** cada objeto que pertence ao conjunto.
		🔹A expressão "bem definida" significa que é possível afirmar com certeza se um objeto pertence ou não ao conjunto.

## ✍️ **Notação**
	* Um conjunto é geralmente representado por letras maiúsculas 𝐴, 𝐵, 𝐶, ...
	* Seus elementos são escritos entre chaves:
			𝐴 = {1,2,3}	ou	𝐴 = {01,10,11}

## 📌 **Pertinência**
	Para indicar se um elemento pertence ou não a um conjunto, usamos:
		* 𝒙 ∈ 𝐴 == "x pertence ao conjunto A"
		* 𝒙 ∉ A == "x não pertencer ao conjunto A" 
	**Exemplo:**
		Seja 𝐴 = {1,2,3}	ou	𝐴 = { 01,10,11}
			* 2 ∈ 𝐴 
				* 10 ∈ 𝐴
			* 5 ∉ 𝐴
				* 101 ∉ 𝐴

## 💡 **Representações de conjuntos**
	1. Por extensão (listando os elementos):
		 <span style="font-family: STIXTwoMath-Regular;">
     𝐵
 </span> **=** {a, e, i, o, u}
	1. Por compreensão (usando uma propriedade):
		 <span style="font-family: STIXTwoMath-Regular;">
     𝐶
 </span> = {  <span style="font-family: STIXTwoMath-Regular;">
     𝒙
 </span>  <span style="font-family: AppleSymbols;">
     ∈
 </span> N | 𝒙 < 5} ⇒ {0,1,2,3,4}

## ✅ **Características de um conjunto**
	* Não já repetições de elementos
		{1,2,2,3} = {1,2,3}
	* A ordem dos elementos não importa
		{𝑎,𝑏,𝑐} = {𝑐,𝑏,𝑎}

## 🧠 **Dicas importantes**
	* Nem toda coleção é um conjunto:
		"Os números bonitos" não é um conjunto, pois a beleza não é bem definida.
	* Evite confundir conjuntos com sequências  <span style="font-family: .PingFangUITextSC-Regular;text-align: left;">
     — conjunto não tem ordem nem duplicação. 
 </span>

# 1.2.3. Pertinência (∈, ∉)

# 
## **🎯 Objetivo**
	Compreender como expressar se m elemento pertence ou não a um conjunto, utilizando os símbolos matemáticos corretos e aplicando isso em situações simples e compostas;

 <span style="font-family: .AppleColorEmojiUI;">
     ## 📚
 </span> <span style="font-family: .AppleColorEmojiUI;">
     **Definição**

 </span>	 <span style="font-size: 16.0;">
     A relação de pertinência indica se um elemento faz parte de um conjunto:

 </span>		* Usamos o símbolo ∈ para dizer que o elemento pertence ao conjunto;
		* Usamos o símbolo ∉ para fizer que o elemento não pertence ao conjunto;

## ✍️ Sintaxe e leitura
	* 𝑥 ∈ 𝐴 → "x pertence a A"
	* 𝑥 ∉ 𝐵 → "x não pertence a B"

## 📌 Exemplos simples
	Seja 𝐴 = {2, 4, 6, 8}:
		* 4 ∈ 𝐴 → ✅ Verdadeiro
		* 5 ∉ 𝐴 → ✅ Verdadeiro
	Seja B = {a, e, i, o, u}:
		* e ∈ 𝐵
		* b ∉ 𝐵

## ⚠️ Cuidado: elementos vs subconjuntos
	Seja 𝐶 = {1, 2, {3,4}
		* 1  <span style="font-family: AppleSymbols;text-align: left;">
     ∈
 </span>  <span style="font-family: STIXTwoMath-Regular;text-align: left;">
     𝐶
 </span> → ✅ Verdadeiro
		* {3, 4}  <span style="font-family: AppleSymbols;text-align: left;">
     ∈
 </span>  <span style="font-family: STIXTwoMath-Regular;text-align: left;">
     𝐶
 </span> → ✅ Verdadeiro
		* 3  <span style="font-family: AppleSymbols;text-align: left;">
     ∈
 </span>  <span style="font-family: STIXTwoMath-Regular;text-align: left;">
     𝐶
 </span> → ❌ Falso (está dentro de um subconjunto, não diretamente em  <span style="font-family: STIXTwoMath-Regular;text-align: left;">
     𝐶
 </span>)

## 🧠 Dicas importantes
	* O símbolo ∈ só é usado para elemento pertencente a conjunto.
		Ex.: 3 ∈ ℕ, mas não se usa {3} ∈ ℕ 
	* Se o conjunto dentro do conjunto, a relação correta pode ser a inclusão (que veremos depois): ⊂

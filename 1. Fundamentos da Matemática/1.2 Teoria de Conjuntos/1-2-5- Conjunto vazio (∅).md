# 1.2.5. Conjunto vazio (∅)


```
	📢"O conjunto vazio é tipo aquele grupo do WhatsApp que ninguém nunca falou nada: existe, mas não tem ninguém."

```


## 💀 O que é o conjunto vazio?
	O conjunto vazio, representado por ∅ ou {}, é um conjunto que não contem nenhum elemento. Definição formal:
		Um conjunto é dito vazio se há nenhum elemento que pertença a ele.
	Exemplo lógico
    		A = {x ∈ ℕ | x < 0} → A = ∅
	Não existe número natural menor que zero, então esse conjunto não tem elementos.

## 📌 Representações
| Notação                  | Significado              |
|--------------------------|--------------------------|
| ∅                        | Conjunto vazio           |
| { }                      | Outra forma de escrever  |
| A = ∅                    | A é um conjunto sem nada |
| A = { }                  | Mesmo que acima          |

	⚠️ Cuidado: ∅ ≠ {∅}
		* ∅ → Conjunto sem nada
		* {∅} → Conjunto com um elementos: O conjunto vazio.

## 🧠 Propriedades importantes
	1. 🔹 Todo conjunto tem um subconjunto vazio
		Se A é qualquer conjunto, então ∅ ⊆ A
	1. 🔹 Interseção de conjuntos disjuntivos é vazia
        	Se A ∩ B = ∅ → não têm elemento em comum
	1. 🔹Cardinalidade do ∅ é 0
        	|∅| = 0 (quantidade de elementos)
	1. 🔹 ∅ ≠ 0
        	Zero é um número, ∅ é um conjunto. Eles vivem em galáxias diferentes.

## 🌍 Onde isso aparece na vida real?
| Situação                     | Exemplo                      |
|------------------------------|------------------------------|
| Pesquisas sem resultados     | Alunos com nota > 10 → ∅     |
| Filtros vazios em apps       | Produtos com "preço < 0" → ∅ |
| Resolução de equações        | x² = -1 em ℝ → solução = ∅   |
| Interseções lógicas          | Gatos ∩ Peixes = ∅           |


## 🧾 Resumo de prova:
| Item                             | Valor                            |
|----------------------------------|----------------------------------|
| Nome                             | Conjunto Vazio                   |
| Símbolo                          | ∅ ou { }                         |
| Cardinalidade                    | 0                                |
| Pertence a si mesmo?             | Não                              |
| ∅ ⊆ A                            | Sempre verdadeiro                |
| ∅ ∈ A                            | Só se A contiver ∅ como elemento |


## 🎯 Conclusão direta:
    O conjunto vazio é o ponto zero da teoria dos conjuntos. Ele não contém nada, mas tá em tudo: É o chão onde a lógica pisa.

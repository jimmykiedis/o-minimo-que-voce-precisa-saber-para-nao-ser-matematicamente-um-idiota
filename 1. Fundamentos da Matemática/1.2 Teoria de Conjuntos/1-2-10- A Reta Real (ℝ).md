# 1.2.10. A Reta Real (ℝ)

# 

```
	📍A linha infinita onde vivem todos os números reais — dos irracionais aos inteiros, tudo junto e misturado.

```


## 🎯O que é a reta real?
	A reta real é um alinha continua, infinita pros dois lados, onde cada ponto representa um número real. Ela organiza e posiciona os números conforme seu valor - menor para esquerda, maior para a direita.
	É a base visual para entender intervalos, distância, vizinhança, limites e praticamente todo o calculo.

## 🧠Estrutura da reta:
| Posição        | Valor          |
|----------------|----------------|
| ⬅️              | Negativos (−∞) |
| 🎯 Centro       | Zero (0)       |
| ➡️              | Positivos (+∞) |

	E no meio disso tudo temos:
		* ℕ (naturais)
		* ℤ (inteiros)
		* ℚ (racionais)
		* ℝ − ℚ (irracionais)
	Tudo isso junto forma ℝ, o rei da reta. 👑

🔍Pontos importantes:
	1. 📏Distância entre dois pontos = valor absoluto da diferença.
		Ex.: A distância entre 5 e -2 é |5 - (-2)| = 7

	1. 🧮Intervalos na reta são pedaços dessa linha:
		* (a, b) → intervalo aberto
		* [a, b] → intervalo fechado
		* (a, b] ou [a, b) → semiabertos
		* (-∞, ∞) → todos os reais

	1. 🚪Topologia básica:
		Serve pra estudar "vizinhança" e "proximidades", tipo:
			* Um número está "próximo" de 3 se estiver entre 2.9 e 3.1
			* Usamos isso mais pra frente em limites e continuidade.

## ✍️Expressões comuns
| Expressão                              | Significado                            |
|----------------------------------------|----------------------------------------|
| x ∈ (0, 1)                             | x está entre 0 e 1, sem incluir        |
| x ∈ [0, 1]                             | x está entre 0 e 1, incluindo os dois  |
| x ∈ (−∞, 3]                            | x é qualquer número menor ou igual a 3 |


## 🧠Resumo
| Coisa                                             | Explicação rápida                                 |
|---------------------------------------------------|---------------------------------------------------|
| Reta real (ℝ)                                     | Linha onde cada ponto = um número real            |
| Posição dos números                               | Menores pra esquerda, maiores pra direita         |
| Intervalos                                        | Partes da reta com início/fim abertos ou fechados |
| Importância                                       | Visualização de tudo que envolve "variação"       |

# 1.1.3. Racionais (ℚ)


```
	📢 "Nem tudo na vida é inteiro, meu consagrado. Às vezes, você só tem meio pão."

```


## 🧠 Introdução
	Os naturais serve para contar o que tem.
	Os inteiros serve para contar o que tem ou o que deve.
	Mas aí alguém quis dividir um bolo em 3 partes iguais e se ferrou tentanto dizer quanto era cada pedaço usando só inteiro. 😵
	Foi aí que nasceu o conjunto dos números racionais (ℚ)
	Números que podem ser escritos como fração entre dois inteiros.

## 🔢 O que é ℚ?
	ℚ = { a / b | a, b ∈ ℤ e b ≠ 0 } 
		📌 Ou seja:
			* Pode ser fração: 1/2, -3/4
			* Pode ser inteiro disfarçado: 5 = 5/1
			* Pode ser decimal exato: 0,25 = 1/4
			* Pode ser dizima periódica: 0,333... = 1/3
	O "ℚ" vem de "quociente", por que o racional é o quociente de dois inteiros.

## 💡 Características dos racionais
	1️⃣ Tem frações, inteiros e decimais finitos ou repetitivos
	2️⃣ Fechado para todas as 4 operações matemáticas.
		✔️ Soma, subtração, multiplicação e divisão (exceto por zero, claro)
	3️⃣ Entre dois racionais, sempre tem outro racional
		→ Isso mostra que ℚ é denso, mas não é completo (spoiler: ℝ que é)

## 📉 Representações decimais dos racionais
| Tipo               | Exemplo            | Observação         |
|--------------------|--------------------|--------------------|
| Decimal exato      | 0.75               | Termina            |
| Dízima periódica   | 0.333…             | Repetição infinita |
| Inteiro disfarçado | 7 = 7/1            | Ainda é racional   |

	🧠 Se o número repete ou termina, ele é racional.

## 🧪 Exemplos do mundo real
| Situação             | Exemplo              |
|----------------------|----------------------|
| Dinheiro             | R\$ 0,50             |
| Receita de bolo      | 3/4 xícara de açúcar |
| Medidas              | 1,5 metros           |
| Divisão de conta     | 1/3 da pizza         |
|                      |                      |

| Símbolo                               | ℚ                                     |
| Definição                             | ℚ = {a / b a, b ∈ ℤ e b ≠ 0}          |
| Inclui frações?                       | ✅ Sim                                 |

## 🎯 Conclusão direta
	ℚ é o conjunto da galera que divide bem: metade do bolo, 1/3 da piza, 0.75 da esperança de passar de ano.
	Se dá para escrever com fração, é racional.💡

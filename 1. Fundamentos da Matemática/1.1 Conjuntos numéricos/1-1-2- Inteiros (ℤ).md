# 1.1.2. Inteiros (ℤ)


```
	📢 "Quando a vida começou a cobrar dívidas, o ser humano inventou os negativos."

```


## 🧠Introdução
	Os números naturais (ℕ) servem para contar o que a gente tem. Mas e quando você deve algo? tipo:
		* "Tenho -50 reais na conta."
		* "A temperatura está -3°C."
		* O personagem tá com -12 de vida (já morrei faz tempo).
	Foi aí que os matemáticos pensaram:
		"E se os números também pudessem andar pra trás?"
	E então nasceu o conjunto dos números inteiros (ℤ).

## 🔢O que é ℤ?
	ℤ = {..., -3, -2, -1, 0, 1, 2, 3, ...}
		📍**Características**:
				* Inclui os números naturais positivos, o zero e os negativos.
				* Não tem fração, nem dízima, nem vírgula.
				* É simétrico em torno do zero (para cada positivo tem um negativo)
		O símbolo de ℤ vem de Zahlen, que é "números" em alemão.
        (Alemão gosta de nomes duros para ideias simples.)

## 📜 Subconjuntos dentro de ℤ:
| Subconjunto        | Notação            | Definição          |
|--------------------|--------------------|--------------------|
| Inteiros positivos | ℤ⁺ ou ℕ*           | {1, 2, 3, ...}     |
| Inteiros negativos | ℤ⁻                 | {..., -3, -2, -1}  |
| Zero               | {0}                | Neutro             |


## ⚖️ Propriedades dos inteiros
	1️⃣ Fechamento pra soma e subtração
		Se somar ou subtrair dois números, ainda dá inteiro.
		✔️ Ex: (-3) + 5 = 2
	2️⃣ Não é fechado pra divisão!
		⚠️ 4 ÷ 3 = 1.333... → Isso não é inteiro. Cuidado!
	3️⃣ Simetria
		Pra todo x ∈ ℕ, existe -x ∈ ℤ.

## 📊 Inteiros na vida real
| Situação                 | Exemplo                  |
|--------------------------|--------------------------|
| Temperatura              | -10°C no inverno         |
| Dívidas bancárias        | -500 reais               |
| Altitude abaixo do mar   | -300 metros              |
| Números de vida em jogos | HP: -12 = morreu         |

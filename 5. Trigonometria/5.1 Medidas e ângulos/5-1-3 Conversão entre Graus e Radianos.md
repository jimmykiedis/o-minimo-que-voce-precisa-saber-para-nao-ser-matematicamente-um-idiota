# 5.1.3 Conversão entre Graus e Radianos


## 📚Por que converter Graus e radianos?
	Na trigonometria, existem dois sistemas principais para medir ângulos: **graus (°)**  e **radianos (rad)**. 
		👉Muitas vezes, os exercícios e problemas pedem para fazer cálculos em uma unidade, enquanto os dados estão em outra.
		👉Além disso, em matemática mais avançada (principalmente no Cálculo), os radianos se tornam a unidade padrão.;
	Por isso, é fundamental saber fazer a conversão entre essas duas unidades.

## 🧠Relação fundamental entre graus e radianos:
	Sabemos que:
		**360°  =  2** <span style="font-family: STIXTwoMath-Regular;">
     𝜋
 </span> **rad**
	Dividimos os dois lados por 2:
		**180°  =**   <span style="font-family: STIXTwoMath-Regular;">
     𝜋
 </span> **rad**

## 📐Fórmulas de conversão:
	Para converter de **graus** **para** **radianos** (é o mais comum de acontecer):
		radianos = graus × (𝜋/180°)

	Para converter de **radianos para graus**:
		graus = radianos × (180°/𝜋)

## ✍️Exemplos práticos:
	🧮Converter 120° para radianos:
		radianos = 120° × (𝜋/180°)
			120𝜋 / 180°
			🔎Aqui vamos simplificar por 60.
				2𝜋 / 3 rad

	🧮Converter 135° para radianos:
		radianos = 135° × (𝜋/180°)
			135𝜋 / 180°
			🔎Aqui deu pra fazer simplificação por 45.
				3𝜋 / 4 rad

	🧮Converter (𝜋 / 3) rad para graus:
		graus = 𝜋 / 3 × (180°/𝜋)
			180𝜋 / 3𝜋 = 60°

## ✅ Dica importante
	Sempre que for fazer a conversão:
		* Se estiver partindo de graus ➔ multiplica por (𝜋/180)
		* Se estiver partindo de radianos ➔ multiplica pelo inverso (180/𝜋)

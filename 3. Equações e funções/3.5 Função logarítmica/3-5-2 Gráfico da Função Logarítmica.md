# 3.5.2 Gráfico da Função Logarítmica


## 🔑📊Definição
	O gráfico de uma função logarítmica tem um formato característico de curva que cresce lentamente.
		se 𝑎 > 1, o gráfico é **crescente**.
		se 0 < 𝑎 < 1, o gráfico é **decrescente.**
	🔎 O gráfico nunca toca o eixo 𝑦 (Não existe logaritmo de numero zero ou negativo).

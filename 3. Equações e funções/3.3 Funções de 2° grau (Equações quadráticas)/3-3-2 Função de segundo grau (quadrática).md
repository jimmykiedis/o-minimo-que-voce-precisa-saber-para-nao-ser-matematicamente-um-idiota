# 3.3.2 Função de segundo grau (quadrática)


## 🫚🔲 Definição
	A função quadrática, também conhecida como função de segundo grau, é uma das funções polinomiais mais importantes da matemática. Ela aparece sempre que existe uma **relação envolvendo o quadrado de uma variável**.
	Sua forma é:
		𝑓(𝑥) = 𝑎𝑥<sup>2 </sup>+ 𝑏𝑥 + 𝑐

	Onde:
		* 𝑎, 𝑏 e 𝑐 são reais (sendo 𝑎 ≠ 0)
		* 𝑥 é a variável independente 
		* 𝑓(𝑥) é a variável dependente (o resultado)


##  📚Características principais da função quadrática:
	1. **Gráfico:**
		O gráfico de uma função quadrática é uma **parábola**, que pode ter concavidade volta para cima ou para baixo.
	1. Concavidade:
		* Se  <span style="font-family: STIXTwoMath-Regular;text-align: left;">
     𝑎
 </span> > 0  <span style="font-family: ZapfDingbatsITC;text-align: left;">
     ➔
 </span> Parábola para cima ⬆️
		*  Se  <span style="font-family: STIXTwoMath-Regular;text-align: left;">
     𝑎
 </span> < 0  <span style="font-family: ZapfDingbatsITC;text-align: left;">
     ➔
 </span> Parábola para baixo ⬇️
	2. Pronto do vértice:
		O vértice da parábola representa o ponto mínimo (se a concavidade for para cima) ou ponto máximo (se a concavidade for para baixo).
			👉 Fórmulas importantes para encontrar o vértice 
				Abcissa do vértice (posição no eixo x):
					𝑥 <span style="font-family: STIXTwoMath-Regular; font-size: 13.0;">
     <sub>𝑣</sub>
 </span> = -𝑏 / 2*𝑎
						🔎Você precisará calcular a mínima/máxima para saber onde a concavidade encontrar seu menor valor no eixo x (horizontalmente), então você só precisar procurar a *"profundidade"* onde será o ponto no eixo y também (verticalmente).
				Ordenada do vértice (posição no eixo y):
					𝑦 <span style="font-family: STIXTwoMath-Regular; font-size: 13.0;">
     <sub>𝑣</sub>
 </span> = 𝑓(𝑥 <span style="font-family: STIXTwoMath-Regular; font-size: 13.0;">
     <sub>𝑣</sub>
 </span>)
						🔎Quando você calcula o valor da abcissa do  vértice, você joga ela na função substituído o 𝑥, o resultado de todo o cálculo será o valor da posição do eixo y da ordenada.
			
## 📚Como encontrar as raízes (ou zeros) da função?
	As raízes são os pontos onde a parábola cruza o eixo x, e podem ser encontradas usando a famosa **Fórmula de Bhaskara**. Comumente ela pode ter dar 3 tipos e resultados, 2 valores reais, 1 valor real apenas ou nenhum valor real, ou seja, a parábola pode cruzar o eixo x duas vezes, uma única vez ou nenhuma vez, respectivamente.
		**Fórmula de Bhaskara:**
			𝑥 = (-𝑏 ± √(𝑏<sup>2</sup> - 4 ⋅ a ⋅  <span style="font-family: STIXTwoMath-Regular;">
     𝑐
 </span>)) / (2 ⋅  <span style="font-family: STIXTwoMath-Regular;">
     𝑎
 </span>)	ou	𝑥 = (-𝑏 ± √Δ) / (2 ⋅  <span style="font-family: STIXTwoMath-Regular;">
     𝑎
 </span>)
		Onde o Δ = 𝑏<sup>2</sup> - 4 ⋅ a ⋅  <span style="font-family: STIXTwoMath-Regular;">
     𝑐 
 </span>é o descriminante, que determina a quantidade de raízes reais da função.
			🔎Você pode fazer o delta antes para descobrir se a raiz será real (distintas ou iguais) ou não.

## 📚Análise gráfica com base no valor de Δ
| Valor de Δ                                                                                                                                         | Significado                                                                                                                                        | Número de raízes reais                                                                                                                             |
|----------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| Δ > 0                                                                                                                                              | Duas raízes reais distintas                                                                                                                        | 2 (X' e X''), significa que a parábola cruzará o eixo x em 2 pontos e que seu ponte de mínima/máxima estará depois do eixo x.                      |
| Δ = 0                                                                                                                                              | Uma raíz real (raízes coincidentes)                                                                                                                | 1 (X), significa que a parábola só cruzará o eixo x uma única vez(no seu ponto de mínima/máxima), por isso dizemos que ela apenas "toca" o eixo x. |
| Δ < 0                                                                                                                                              | Nenhuma raíz real                                                                                                                                  | 0 (∄), funcionaria apenas se lidássemos com números complexos (𝑖), afinal, não existe raiz quadrada  de número negativo.                           |

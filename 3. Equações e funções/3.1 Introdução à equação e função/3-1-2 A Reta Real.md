# 3.1.2 A Reta Real


# 🚊Introdução
	Até agora, aprendemos que os números podem ser representado de diferentes maneiras. Podemos, por exemplo, organizar números em uma sequência, compara qual é maior ou menor e até trabalhar com números positivos e negativos. Mas podemos fazer algo ainda mais interessante:
		> Podemos representar cada numero como uma posição em uma reta.
	Essa repetenarão é chamada de reta real:
		Imagine uma reta que se estende infinitamente para os dois lados, nem escolhemos um ponto de referencia chamado de zero (0). A partir dele:
			* ➡️ para a direita, os números aumentam;
			* ⬅️ para a esquerda, os números diminuem.
	Podemos representá-la assim:
		←——+—-+—-+—-+—-+—-+—→
			-2	-1	0	1	2	3		
	Assim, a reta funciona como uma espécie de mapa dos números: Cada número possui uma posição específica.
	Mas como podemos imagina isso de uma maneira mais fácil?

# 🚂Exemplo lógico: A ferrovia do Velho Oeste
	Imagine uma enorme ferrovia atravessando o os estados americanos de leste à oeste. 🏜️🚂
	Nessa ferrovia existem infinitas estações espalhadas pelo caminho. Para facilitar a localização dos trens, os engenheiros decidiram numerar cada estação. No centro da ferrovia existe uma estação especial:
		> 🚉 Estação 0
	Ela será nosso ponto de referência. A partir dela, as estações para leste (direita) recebem números positivos:
		1, 2, 3, 4, 5…
	Enquanto as estações para a esquerda recebem números negativos:
		-1, -2, -3, -4, -5…

## 	 🚂 Viajando para leste
		Vamos supor que temos uma locomotiva na nossa estação especial chamada zero (0). O supervisor dá as ordem ao maquinista:
			> “Avance uma estação para o leste!”
		A locomotiva vai de:
			0 → 1
		Se avançar mais uma:
			1 → 2
		e mais uma:
			2 → 3
		Perceba que os números estão aumentando conforme a locomotiva vi para a direita:
			1 → 2 → 3 → 4 → 5…
		Portanto:
			> ➡️ Para a direta os números aumentam.

## 	🚂 Viajando para oeste
		E se o maquinista voltar? Imagine se o maquinista percebeu que deixo uma encomenda para trás. 📦
		Ele estava na estação 3 e precisava voltar para o Oeste. Ele começa a retornar:
			3 → 2 → 1 → 0
		Mas ele ainda precisa continuar:
			0 → -1 → -2 → -3, -4…
		Agora encontramos os números negativos. Eles não são simplesmente “ruins” ou “menores que nada” 😄
		Eles simplesmente representam posições que estão do outro lado do nosso ponto de referência. Portanto:
			> ⬅️ Para a esquerda os números esquerda.
## 	
## 	📮Existem mais lugares além das estações!
		Agora vem uma parte importante. Imagine no caminho dessas infinitas estações exista infinitas pequenas paradas entre elas.
			* 📬 Uma parada para pegar cartas e encomendas;
			* 💧 Uma parada para abastecer a caldeira com água;
			* 🌲 Uma parada para retirar galhos sobre os trilhos;
			* ❄️ Uma para para limpar a neve.
		E elas aparecem um distâncias diferentes dos percursos, e se tomássemos como exemplo as estações 2 e 3 do percurso do nosso maquinista, essas paradas podiam ser representadas por números como:
			* 📬 em 2,4;
			* 💧 em 2,65;
			* 🌲 em 2,761;
			* ❄️ em 2,9999.
		E aqui temos uma ideia fundamental:
			> “🧠 Entre dois números reais diferentes, existem infinitos outros números reais.”
		Não existem apenas os números inteiros 2 e 3, existem infinitos números entre eles.

## 	📍 Onde está a locomotiva?
			Imagine que o maquinista diga:
				> “Minha locomotiva está na posição -2.”
			Isso significa que ele está duas unidades para a esquerda da estação 0.
			Se ele disser:
				> “Estou na posição 4.”
			Significa que está quatro unidades para a direita da estação 0.
			E se disser:
				> “Minha localização atual é 2,5.”
			Significa que está exatamente no meio do caminho entre 2 e 3. Portanto cada número representa uma posição especifica na ferrovia. E é assim que podemos pensar na reta real:
				> 🚂 Cada número real corresponde a uma posição na reta.

# ✅Resumo
	A reta real é uma representação dos números reais em uma reta. Nela:
		* 0 é o ponto de referência;
		* Números positivos ficam à direita;
		* Números negativos ficam à esquerda;
		* Quanto mais à direita, maior é o número;
		* Quanto mais à esquerda, menor é o número;
		* Entre dois números reais diferentes existem infinitos outros números;
		* A reta continua infinitamente para os dois lados.

## 	🎯 Para provar isso na prova:
		> 📏 Imagine a reta real como uma ferrovia infinita. O zero é a estação central, os números positivos ficam para a direita e os negativos para a esquerda. Cada número representa uma posição específica onde a locomotiva pode para.
	Ou, de forma ainda mais curta:
		> 🚂 Reta real = uma ferrovia infinita onde cada número tem seu lugar.
	E agora que sabemos representar números em uma dimensão, podemos aprender a representar em duas dimensões.
